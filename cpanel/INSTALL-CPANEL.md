# راهنمای نصب روی هاست سی‌پنل (بدون SSH)

این راهنما قدم‌به‌قدم نصب «سامانه مدیریت کلاس‌ها» را روی هاست اشتراکی سی‌پنل توضیح می‌دهد.
هیچ دسترسی SSH لازم نیست؛ همه مراحل از طریق مرورگر انجام می‌شود.

---

## ۱. پیش‌نیازها

- هاست سی‌پنل با قابلیت **Setup Node.js App** (CloudLinux Node.js Selector)
- نسخه Node.js 18 یا بالاتر (در مرحله ساخت اپ انتخاب می‌کنید)
- (اختیاری) یک دیتابیس MySQL از بخش «MySQL® Databases» سی‌پنل

> اگر هاست شما Node.js ندارد، از پشتیبانی هاست بخواهید «Node.js Selector» را فعال کند.

---

## ۲. آپلود فایل‌ها

1. فایل ZIP پروژه را دانلود کنید.
2. وارد **File Manager** سی‌پنل شوید.
3. فایل‌ها را در `public_html` (یا زیرپوشه دلخواه مثل `public_html/myclass`) آپلود و Extract کنید.
4. فایل `cpanel/.htaccess` را به ریشه برنامه منتقل کنید (روی `public_html/.htaccess`).

---

## ۳. ساخت اپلیکیشن Node.js

1. در سی‌پنل به **Setup Node.js App** بروید.
2. روی **Create Application** بزنید:
   - **Node.js version**: نسخه ۱۸ یا بالاتر
   - **Application mode**: Production
   - **Application root**: پوشه برنامه (مثلاً `public_html` یا `myclass`)
   - **Application URL**: دامنه یا زیرپوشه
   - **Application startup file**: `server.js`
3. روی **Create** بزنید.
4. در همان صفحه، دکمه **Run NPM install** را بزنید تا وابستگی‌ها نصب شوند.

---

## ۴. (اختیاری) ساخت دیتابیس MySQL

1. در سی‌پنل به **MySQL® Databases** بروید.
2. یک دیتابیس بسازید (مثلاً `myclass`).
3. یک کاربر بسازید و به دیتابیس اضافه کنید (All Privileges).
4. نام دیتابیس، نام کاربر و رمز را یادداشت کنید.

> اگر MySQL نمی‌خواهید، گزینه **SQLite** را در نصب‌کننده انتخاب کنید؛ هیچ تنظیم دیتابیسی لازم نیست.

---

## ۵. راه‌اندازی و نصب وب‌محور

1. اپ را در مرورگر باز کنید (دکمه Open در Setup Node.js App یا آدرس دامنه).
2. به مسیر `/install` بروید.
3. مراحل نصب:
   - **مرحله ۱**: بررسی پیش‌نیازها → ادامه
   - **مرحله ۲**: انتخاب SQLite (ساده) یا MySQL (حرفه‌ای) و تست اتصال
   - **مرحله ۳**: نام موسسه، حساب مدیر (ناظر کل) و (اختیاری) کلید پیامک IPPanel
   - **مرحله ۴**: پایان! وارد سامانه شوید.
4. پس از نصب، مسیر `/install` به‌صورت خودکار غیرفعال می‌شود.

---

## ۶. پیکربندی پیامک IPPanel

1. در پنل کاربری [ippanel.com](https://ippanel.com) وارد شوید.
2. مسیر **Developers ← Access Keys** یک کلید دسترسی بسازید.
3. در سامانه: **تنظیمات ← پیامک (IPPanel)**:
   - کلید API را وارد کنید
   - شماره فرستنده (مثل `+983000505`) را تنظیم کنید
   - سرویس را فعال کنید
4. در بخش **پنل پیامک ← الگوها** برای هر رویداد:
   - یک Pattern (پترن) در پنل IPPanel بسازید و کد آن را وارد کنید
   - نگاشت متغیرها (نام کامل، نام کلاس، مبلغ و...) را به پارامترهای پترن تنظیم کنید
5. با دکمه **تست اتصال** از صحت تنظیمات مطمئن شوید.

---

## ۷. نکات امنیتی

- فایل `.htaccess` (از پوشه `cpanel`) حتماً در ریشه برنامه باشد.
- پس از نصب، فایل `data/installed.lock` و پوشه `data/` را از دسترس عموم خارج نکنید ولی مطمئن شوید `.htaccess` آن‌ها را مسدود می‌کند.
- `SESSION_SECRET` در فایل `.env` به‌صورت خودکار تصادفی ساخته می‌شود؛ آن را تغییر ندهید.
- روی دامنه‌های HTTPS، در فایل `.env` مقدار `COOKIE_SECURE=true` را تنظیم کنید.

---

## ۸. عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| صفحه ۵۰۰ هنگام اجرا | از بخش Setup Node.js App لاگ اپ را ببینید؛ معمولاً خطای npm install است |
| `Cannot find module` | دکمه Run NPM install را دوباره بزنید |
| استایل‌ها لود نمی‌شوند | مسیر Application root را بررسی کنید |
| ورود انجام نمی‌شود | کوکی‌ها را پاک کنید؛ مطمئن شوید HTTPS یا HTTP یکنواخت است |
| پیامک ارسال نمی‌شود | در بخش گزارش پیامک، پاسخ سرویس را بررسی کنید |

---

## ۹. به‌روزرسانی

1. نسخه جدید را روی نسخه قبلی Extract کنید (فایل‌های `data/`، `.env` و `public/uploads/` دست‌نخورده می‌مانند).
2. در Setup Node.js App دوباره **Run NPM install** را بزنید.
3. اپ را Restart کنید. مهاجرت‌های پایگاه‌داده به‌صورت خودکار اجرا می‌شوند.
