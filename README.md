# مای‌کلس (MyClass) — سامانه جامع مدیریت آموزشگاه

سامانه تحت وب مدیریت آموزشگاه و کلاس‌ها با **Node.js**، کاملاً **فارسی، راست‌چین و با تقویم شمسی**؛ قابل نصب روی **هاست سی‌پنل بدون نیاز به SSH** (نصب‌کننده تحت وب).

## امکانات

| بخش | توضیحات |
| --- | --- |
| **موسسه و تنظیمات** | ثبت موسسه با نام، لوگو و اطلاعات تماس؛ تنظیمات جامع در زبانه‌های جداگانه (ظاهر، امنیت، مالی، پیامک، مدارک، پیش‌ثبت‌نام، پنل دانشجو، سیستم) |
| **کلاس‌ها** | تعریف کلاس با تاریخ شروع/پایان، ساعت شروع/پایان و روزهای هفته؛ ساخت خودکار جلسات؛ دسته‌بندی، ظرفیت، شهریه، کلاس آنلاین، تقویم جلسات |
| **حضور و غیاب** | ثبت حاضر / غایب / تأخیر / غیبت موجه برای هر جلسه، ماتریس حضور کلاس، خروجی CSV، هشدار پیامکی غیبت |
| **دانشجویان** | تخصیص دانشجو به کلاس‌ها، پنل اختصاصی دانشجو (کلاس‌ها، برنامه، حضور، اقساط، رسید کارت به کارت، مدارک)، ورود گروهی از CSV |
| **اساتید** | تخصیص استاد به کلاس‌های مشخص؛ استاد فقط کلاس‌ها و دانشجویان خودش را می‌بیند |
| **نقش‌ها و دسترسی‌ها** | ساخت نقش‌های دلخواه با مجوزهای ریز (+ محدوده داده: همه / فقط کلاس‌های تخصیصی / فقط خود)، یک نقش برای هر کاربر |
| **امور مالی** | پرداخت نقدی (یکجا) یا اقساطی با پیش‌پرداخت، کارت به کارت با بارگذاری رسید و تأیید/رد کارشناس، یادآوری خودکار اقساط، گزارش‌ها و نمودارها، چاپ فاکتور |
| **پیش‌ثبت‌نام** | فرم عمومی پیش‌ثبت‌نام با کد رهگیری، کپچا و ضد ربات؛ تبدیل یک‌کلیکی به ثبت‌نام قطعی + ساخت حساب + صدور فاکتور |
| **مدارک** | صدور گواهی پایان دوره با قالب‌های قابل طراحی، QR و صفحه عمومی استعلام اصالت، شرایط صدور (حداقل حضور، تسویه حساب) |
| **پیامک (IPPanel Edge)** | پترن جداگانه برای هر رویداد (۲۰+ رویداد)، تعریف متغیرهای ارسالی با ترکیب متن و توکن، دریافت خودکار متغیرهای پترن از پنل، ارسال گروهی، گزارش و ارسال مجدد |
| **داشبورد** | شاخص‌های کلیدی و نمودارهای تعاملی (درآمد، ثبت‌نام، نرخ حضور، وصول مطالبات، روش‌های پرداخت و …) متناسب با نقش کاربر |
| **امنیت** | CSRF، محدودیت تلاش ورود و قفل حساب، هش bcrypt، CSP، Audit Log، کنترل دسترسی در لایه کد و کوئری‌های پایگاه داده |
| **ماژولار** | هر بخش یک ماژول مستقل (منو، مسیر، مجوز، تنظیمات، رویداد پیامک، مایگریشن، زمان‌بند)؛ فعال/غیرفعال‌سازی از پنل |

## پیش‌نیازها

- Node.js نسخه **18.17 یا بالاتر** (پیشنهادی: 20 یا 22)
- پایگاه داده **MySQL / MariaDB** (پیشنهادی برای هاست) — یا **SQLite** (نیازمند Node.js 22.5+)

## نصب روی هاست سی‌پنل (بدون SSH)

1. **ساخت پایگاه داده:** در cPanel بخش *MySQL® Databases* یک پایگاه داده و کاربر بسازید و کاربر را با همه دسترسی‌ها به پایگاه داده اضافه کنید.
2. **آپلود فایل‌ها:** محتوای پروژه (بدون پوشه `node_modules`) را فشرده کنید، با *File Manager* در پوشه‌ای مثل `~/myclass` آپلود و Extract کنید.
3. **ساخت برنامه Node.js:** در cPanel بخش *Setup Node.js App* → *Create Application*:
   - Node.js version: بالاترین نسخه موجود
   - Application mode: `Production`
   - Application root: `myclass`
   - Application URL: دامنه یا ساب‌دامین مورد نظر
   - Application startup file: `app.js`
4. روی **Run NPM Install** کلیک کنید تا وابستگی‌ها نصب شوند، سپس **Restart** را بزنید.
5. آدرس سایت را باز کنید؛ به‌صورت خودکار به **نصب‌کننده تحت وب** (`/install`) هدایت می‌شوید. اطلاعات پایگاه داده، نام موسسه و حساب مدیر کل را وارد کنید (امکان نصب داده‌های نمونه برای آزمایش وجود دارد).
6. **زمان‌بند (اختیاری اما توصیه‌شده):** در *تنظیمات ← سیستم و زمان‌بندی* دستور آماده Cron را کپی کرده و در cPanel بخش *Cron Jobs* با فاصله هر ۵ دقیقه اضافه کنید. (زمان‌بند داخلی هم فعال است، ولی در هاست‌های اشتراکی ممکن است برنامه در زمان بی‌کاری متوقف شود.)

> پس از نصب، فایل `config/config.json` ساخته می‌شود؛ برای نصب مجدد کافی است این فایل را حذف کنید.
> پوشه‌های `config`، `storage` و `src` با `.htaccess` در برابر دسترسی مستقیم محافظت شده‌اند.

## اجرای محلی

```bash
npm install
npm start            # http://localhost:3000
npm test             # تست‌های واحد
```

متغیرهای محیطی اختیاری: `PORT`، `HOST`، `BASE_PATH` (اجرا در زیرپوشه)، `ALLOW_IFRAME=1`.

## اتصال پیامک IPPanel Edge

1. در *تنظیمات ← پیامک* کلید API (یا توکن) و شماره فرستنده را وارد و ارسال را فعال کنید.
2. در پنل IPPanel برای هر رویداد یک پترن بسازید (مثلاً `کاربر گرامی %name%، قسط %amount% تومان شما در تاریخ %date% سررسید می‌شود.`).
3. در *پیامک ← پترن‌ها* رویداد مورد نظر را باز کنید، کد پترن را وارد کرده و «دریافت متغیرها» را بزنید؛ برای هر متغیر مقدار ارسالی را با توکن‌های سامانه تعیین کنید (مثلاً `name` ← `{first_name}`، `amount` ← `{amount}`) و ذخیره کنید. با «ارسال آزمایشی» صحت تنظیمات را بسنجید.

مستندات API: <https://ippanelcom.github.io/Edge-Document/docs/>

## ساختار پروژه

```
app.js                  نقطه ورود (Passenger / cPanel)
src/core/               هسته: پایگاه داده، احراز هویت و دسترسی، تقویم شمسی، تنظیمات، رویدادها، زمان‌بند، رندر
src/modules/<name>/     ماژول‌ها: index.js (مانیفست) + routes.js + service.js + views/
src/installer/          نصب‌کننده تحت وب
src/views/              قالب‌ها و اجزای مشترک
public/                 CSS، JS و کتابخانه‌های کلاینت (ApexCharts، تقویم شمسی، فونت وزیرمتن، آیکون‌ها)
storage/                فایل‌های آپلودی، لاگ‌ها و پایگاه داده SQLite
```

### افزودن ماژول جدید

یک پوشه در `src/modules` بسازید و در `index.js` مانیفست ماژول را export کنید:

```js
module.exports = {
  key: 'library', name: 'کتابخانه', icon: 'book-open', order: 60, requires: ['users'],
  permissions: [{ key: 'library.view', label: 'مشاهده کتابخانه' }],
  menu: [{ label: 'کتابخانه', icon: 'book-open', href: '/panel/library', perm: 'library.view', section: 'education' }],
  settingsTabs: [], settings: [], smsEvents: [], migrations: [], tasks: [],
  userTabs: [], classTabs: [],
  routes(r) { r.get('/library', (req, res) => res.page(/* ... */)); },
};
```

ماژول به‌صورت خودکار بارگذاری می‌شود و از *تنظیمات ← ماژول‌ها* قابل فعال/غیرفعال‌سازی است.
