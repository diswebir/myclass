# 🎓 سامانه جامع مدیریت کلاس‌ها | MyClass Platform

پلتفرم حرفه‌ای مدیریت کلاس‌های آموزشی برای موسسات — **کاملاً فارسی، راست‌چین، با تقویم شمسی**
ساخته‌شده با **Node.js**، قابل نصب روی هاست **سی‌پنل بدون نیاز به SSH**.

---

## ✨ امکانات

### 🏫 مدیریت موسسه و کلاس‌ها
- ثبت سامانه به نام موسسه شما (نام، لوگو، آدرس، برندینگ)
- تعریف نامحدود کلاس با تاریخ شروع/پایان، ساعت، روزهای هفتگی، ظرفیت و شهریه
- تولید خودکار جلسات از روی برنامه هفتگی
- تخصیص استاد به هر کلاس (دسترسی استاد فقط به کلاس‌ها و دانش‌آموزان خودش)

### 👥 دانش‌آموزان و پنل کاربری
- پرونده کامل دانش‌آموز (اطلاعات، سرپرست، سوابق)
- پنل کاربری اختصاصی: کلاس‌ها، جلسات، حضور و غیاب، مالی، مدارک
- **فرم پیش‌ثبت‌نام آنلاین** برای هر کلاس + پنل بررسی درخواست‌ها (تایید/رد)

### ✅ حضور و غیاب
- ثبت سریع حضور/غیبت/تاخیر/غیبت موجه برای هر جلسه
- کارنامه حضور دانش‌آموز و گزارش کلاس‌ها
- پیامک خودکار اطلاع غیبت

### 💰 مالی
- پرداخت **نقدی**، **کارت به کارت** (با آپلود رسید و تایید مدیر) و آنلاین
- **طرح اقساط** با سررسیدهای دلخواه + یادآوری پیامکی قسط‌ها
- گزارش‌های مالی، مطالبات و تسویه‌حساب

### 📜 صدور مدرک
- صدور گواهی پایان دوره با شماره سریال یکتا
- طراحی زیبا، قابل چاپ / ذخیره PDF + **QR استعلام**
- صفحه استعلام عمومی اصالت مدرک (`/verify/سریال`)

### 📱 پنل پیامک IPPanel
- یکپارچه با **IPPanel Edge API** (ارسال با الگو / Pattern)
- برای هر رویداد یک الگوی جداگانه: پیش‌ثبت‌نام، تایید، پرداخت، یادآوری قسط، غیبت، مدرک و...
- **نگاشت متغیرها کاملاً قابل تنظیم**: هر متغیر سیستم (نام، کلاس، مبلغ، تاریخ...) را به هر پارامتر پترن وصل کنید
- گزارش کامل ارسال‌ها، ارسال تکی/گروهی/تستی و تست اتصال

### 🔐 امنیت و سطوح دسترسی (RBAC)
- ساخت **سطوح دسترسی دلخواه** با ماتریس کامل دسترسی‌ها
- تخصیص نقش به هر کاربر؛ محدودسازی دامنه‌ای (استاد/دانش‌آموز) در سطح کد و کوئری‌ها
- رمزنگاری bcrypt، جلسات امن در پایگاه‌داده، محافظت CSRF، محدودسازی نرخ درخواست، هدرهای CSP
- ثبت گزارش رویدادها (Audit Log) تمام اقدامات حساس

### ⚙️ تنظیمات جامع
- اطلاعات موسسه، تنظیمات آموزشی، مالی، پیامک، مدرک، امنیت و ظاهر (رنگ اصلی، تم تیره/روشن)
- **ماژولار**: هر قابلیت یک ماژول است و می‌توانید آن را فعال/غیرفعال کنید

### 📊 داشبورد حرفه‌ای
- کارت‌های آماری زنده + نمودارهای Chart.js (درآمد، ظرفیت، حضور و غیاب، پیش‌ثبت‌نام)
- تقویم شمسی اختصاصی (Datepicker)، اعداد و مبالغ فارسی، کاملاً RTL

## 🧱 معماری

```
myclass/
├── server.js              # نقطه شروع (سازگار با Passenger سی‌پنل)
├── migrations/            # مهاجرت‌های پایگاه‌داده (خودکار)
├── seeds/                 # داده‌های اولیه (نقش‌ها، دسترسی‌ها، الگوهای پیامک)
├── src/
│   ├── app.js             # ساخت اپ Express
│   ├── core/              # هسته: auth، rbac، csrf، sms، db، ابزارها
│   ├── modules/           # ماژول‌های کارکردی (modular)
│   │   ├── classes/  students/  attendance/  payments/
│   │   ├── certificates/  sms/  enrollments/  reports/
│   │   ├── users/  roles/  settings/  portal/  ...
│   ├── views/             # قالب‌های EJS (RTL فارسی)
│   └── public/            # CSS/JS/فونت وزیرمتن/آپلودها
├── cpanel/                # فایل‌های نصب سی‌پنل (.htaccess + راهنما)
└── .env.example           # نمونه پیکربندی
```

- **پایگاه‌داده**: SQLite (بدون پیکربندی) یا MySQL/MariaDB — هر دو کامل
- **بدون وابستگی به CDN**: فونت، چارت و تقویم داخل پروژه
- **نصب وب‌محور**: `/install` — بدون SSH

---

## 🚀 نصب سریع (سی‌پنل، بدون SSH)

1. فایل‌ها را در هاست آپلود کنید
2. در **Setup Node.js App** یک اپ با فایل شروع `server.js` بسازید و `npm install` را بزنید
3. به `/install` بروید و مراحل نصب را طی کنید (SQLite یا MySQL + حساب مدیر)
4. وارد پنل شوید و از **تنظیمات** سامانه را شخصی‌سازی کنید

📖 راهنمای کامل: [cpanel/INSTALL-CPANEL.md](cpanel/INSTALL-CPANEL.md)

## 💻 اجرا روی سیستم محلی

```bash
npm install
npm start        # یا npm run dev برای توسعه
# http://localhost:3000/install
```
