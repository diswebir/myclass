# راهنمای عیب‌یابی خطاهای متداول در هاست‌های cPanel

## ۱. خطای 503 Service Unavailable یا عدم اجرای Node.js App
- **علت ۱:** فایل `app.js` در ریشه پوشه برنامه قرار ندارد یا نام فایل Startup اشتباه وارد شده است.
  - **راه‌حل:** در Setup Node.js App بررسی کنید فیلد Application Startup File دقیقاً `app.js` باشد.
- **علت ۲:** ماژول‌ها ساخته نشده‌اند یا دستور build اجرا نشده است.
  - **راه‌حل:** پوشه `dist/` باید در ریشه برنامه موجود باشد.

## ۲. خطای خط اتصال به پایگاه داده (Database Connection Error)
- **علت ۱:** دسترسی کاربر دیتابیس کامل نیست.
  - **راه‌حل:** در cPanel -> Manage User Privileges مطمئن شوید تیک **ALL PRIVILEGES** برای کاربر پایگاه داده زده شده است.
- **علت ۲:** پیشوند نام کاربری یا دیتابیس سی‌پنل جا افتاده است.
  - **راه‌حل:** نام دیتابیس در هاست اشتراکی به شکل `username_dbname` است و باید به طور کامل وارد شود.

## ۳. خطای فونت یا نمایش نادرست متون فارسی
- تمام فایل‌های فونت رسمی Vazirmatn در مسیر `public/assets/fonts/` به صورت محلی قرار دارند و نیازی به ارتباط با هیچ سرور خارجی یا CDN وجود ندارد.
- مطمئن شوید مجوز خواندن فایل‌های این پوشه در هاست حداقل ۶۴۴ باشد.

## ۴. بررسی وضعیت سلامت و لاگ سرور
- در صفحه مدیریت، لینک **«بررسی سلامت سرور»** وضعیت لحظه‌ای دیتابیس، حافظه رم و آپتایم را نمایش می‌دهد.
- همچنین فایل‌های لاگ استقرار Passenger را می‌توانید در پوشه برنامه با نام `stderr.log` در cPanel File Manager مشاهده فرمایید.
