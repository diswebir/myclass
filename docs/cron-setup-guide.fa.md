# راهنمای تنظیم Cron Jobs در cPanel برای پردازش پس‌زمینه صف پیامک و اقساط

برای پردازش صف پیامک‌ها و به‌روزرسانی وضعیت اقساط سررسیدشده، دو روش کاملاً استاندارد و سازگار با محدودیت‌های cPanel اشتراکی فراهم شده است:

---

## روش اول: اجرای مستقیم اسکریپت با Node (توصیه‌شده)
1. وارد cPanel شوید و از بخش **Advanced** روی گزینه **Cron Jobs** کلیک کنید.
2. در بخش **Add New Cron Job**:
   - زمان‌بندی را روی هر ۵ دقیقه یا هر ۱۰ دقیقه تنظیم کنید:
     `*/5 * * * *`
   - در فیلد **Command** دستور زیر را با اصلاح مسیر پوشه پروژه خود وارد کنید:
     ```bash
     /usr/local/bin/node /home/YOUR_CPANEL_USER/academy/dist/jobs/run.js >/dev/null 2>&1
     ```
     *(توجه: مسیر دقیق باینری node را می‌توانید در صفحه Setup Node.js App مشاهده کنید).*
3. روی دکمه **Add New Cron Job** کلیک کنید.

---

## روش دوم: فراخوانی وب‌هوک داخلی با کلید محرمانه (بدون وابستگی به مسیر Node)
اگر دسترسی به مسیر باینری Node در هاست محدود بود:
1. در بخش **Cron Jobs** در فیلد **Command** از دستور `curl` با توکن محرمانه استفاده کنید:
   ```bash
   curl -s "https://your-domain.com/api/cron/run?token=YOUR_CRON_SECRET" >/dev/null 2>&1
   ```
2. مقدار `YOUR_CRON_SECRET` دقیقاً همان مقداری است که در متغیرهای محیطی با نام `CRON_SECRET` تنظیم کرده‌اید.
3. با این روش، وب‌سرور داخلی سامانه هر ۵ دقیقه صف را بررسی و ارسال می‌کند.
