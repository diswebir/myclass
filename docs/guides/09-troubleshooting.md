# راهنمای عیب‌یابی و حل خطا

این راهنمای عیب‌یابی و حل مشکل‌های مهم اپلیکیشن است.

## گام ۱ — بررسی سلامت اپ

ابتدا از بخش‌های زیر بررسی کنید:

1. `/admin/health` را باز کنید (باید `ok` نمایش دهد).
2. در cPanel، بخش **Logs** را مشاهده کنید.
3. در صورت خطا، اپ را Restart کنید.

## گام ۲ — خطا‌ی: `Cannot find module ... dist/index.js`

این خطا یعنی:

```
Error: Cannot find module 'C:\laragon\www\myclass\dist\index.js'
```

علت: پوشه‌ی `dist/` ساخته نشده است (فایل‌های Build وجود ندارند).

1. در مسیر پروژه (پوشه‌ی myclass) اجرا کنید:

```
npm run build
```

2. یا از فایل ZIP رسمی (که شامل `dist/` است) استفاده کنید.

> نکته: ZIPهای ارسالی شامل `dist/` هستند.

## گام ۳ — تنظیم PORT در Windows

دستور `PORT=3040 npm start` فقط در bash کار می‌کند؛ در Windows:

```
PORT=3040 npm start
```

در CMD:

```
set PORT=3040 && npm start
```

در PowerShell:

```
$env:PORT=3040; npm start
```

## گام ۴ — جدول خطا‌های مهم

| پیام خطا | علت | راه‌حل |
|---|---|---|
| اپ اجرا نمی‌شود | در cPanel، log را بررسی کنید | اپ را از cPanel Restart کنید |
| اتصال به پایگاه داده ناموفق | فایل `.env` را بررسی کنید | مقادیر `DB_*` در `.env` را بررسی کنید |
| پیامک ارسال نمی‌شود | `SMS_LIVE_TESTS` و cron را بررسی کنید | راهنمای 04 و 05 را باز کنید |
| خطای 403 (CSRF) | صفحه را دوباره بارگذاری کنید | صفحه را Refresh کنید |

## گام ۵ — راهنمای بیشتر

1. `README.md` را باز کنید.
2. پوشه‌ی `docs/` را بررسی کنید.
3. پوشه‌ی `docs/guides/` را باز کنید.

برای سؤال بیشتر، `README.md` و `docs/` را بررسی کنید.
