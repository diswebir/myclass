# راهنمای کاربران، نقش‌ها و دسترسی‌ها

در این راهنمای سیستم نقش و دسترسی (RBAC) توضیح داده می‌شود.

## گام ۱ — نقش‌ها و دسترسی‌ها

| نقش | عنوان | توضیح |
|---|---|---|
| `admin` | مدیرکل | دسترسی کامل |
| `teacher` | استاد | دسترسی به کلاس |
| `student` | دانش‌آموز | دسترسی به پنل دانش‌آموز |

## گام ۲ — افزودن کاربر (`/admin/users`)

1. `/admin/users` را باز کنید.
2. اطلاعات زیر را وارد کنید:
   - **نام**: نام کامل
   - **نام کاربری**: ...
   - **موبایل**: شماره موبایل
   - **نقش**: انتخاب کنید (از فهرست)
3. ذخیره کنید.

## گام ۳ — تخصیص نقش به کاربر

1. در `/admin/users`، ویرایش را انتخاب کنید.
2. در سطر «نقش»، نقش مورد نظر را انتخاب کنید.
3. برای تأیید، ذخیره کنید.

> نکته: لینک دانش‌آموز به کاربر، از صفحه‌ی `/students` انجام می‌شود.

## گام ۴ — فهرست دسترسی‌ها (`/admin/permissions`)

`/admin/permissions` — فهرست کامل دسترسی‌ها مشاهده می‌شود:

| دسترسی | عنوان | توضیح |
|---|---|---|
| `students.view` | مشاهده‌ی دانش‌آموزان | read |
| `students.create` | افزودن دانش‌آموز | write |
| `finance.payments.approve` | تأیید پرداخت‌ها | write |
| `users.manage` | مدیریت کاربران | write |
| `settings.edit` | ویرایش تنظیمات | write |
| `backup.run` | اجرا پشتیبان | write |

> نکته‌ی: wildcard `*:*` یعنی دسترسی کامل.

## گام ۵ — بررسی دسترسی‌ها

برای بررسی دسترسی‌ها:

1. `/admin/audit` را باز کنید.
2. جدول را مشاهده کنید.
3. نتیجه را بررسی کنید.

برای رفع خطا، `09-troubleshooting.md` را باز کنید.
