# راهنمای پشتیبان و بازیابی

این راهنمای پشتیبان‌گیری و بازیابی داده‌ها است.

## گام ۱ — پشتیبان‌گیری

1. `/admin/backup` را باز کنید.
2. گزینه‌ی «پشتیبان‌گیری» را انتخاب کنید.
3. فایل zip شامل `schema.sql` و فایل‌ها (storage) دانلود می‌شود.

> هشدار: `ENCRYPTION_KEY` را تغییر ندهید؛ در غیر این صورت، داده‌های رمزنگاری‌شده خوانده نمی‌شوند.

## گام ۲ — محل ذخیره

- محل: `../storage/backups` (در `STORAGE_DIR`)
- محتوا: `schema.sql` (database) + فایل‌ها + حجم (KB/MB)
- تعداد: آخرین 10 پشتیبان ذخیره می‌شوند.

## گام ۳ — بازیابی

1. `/admin/backup/restore` را باز کنید.
2. در صفحه، فایل zip را انتخاب کنید.
3. برای شروع بازیابی تأیید کنید.
4. اپ را **Restart** کنید.

> هشدار: بازیابی، داده‌های فعلی را با داده‌های پشتیبان جایگزین می‌کند؛ ابتدا پشتیبان گیری کنید.

## گام ۴ — زمان‌بندی cron (Cron Jobs)

برای پشتیبان خودکار هر روز:

```
0 3 * * * cd /home/USER/myclass && npm run backup:cli
```

یا با mysqldump:

```
0 3 * * * mysqldump -u USER -pPASS user_myclass > /home/USER/backups/db-$(date +%F).sql
```

## گام ۵ — بازبینی

برای بازبینی پشتیبان‌ها:

1. آخرین پشتیبان را بررسی کنید.
2. `/admin/backup` را باز کنید.
3. نتیجه پشتیبان را بررسی کنید.

برای رفع خطا، `09-troubleshooting.md` را باز کنید.
