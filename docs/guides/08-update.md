# راهنمای به‌روزرسانی

این راهنمای به‌روزرسانی اپلیکیشن است.

## گام ۱ — پشتیبان‌گیری قبل از به‌روزرسانی

ابتدا از بخش پشتیبان‌گیری (راهنمای 07) پشتیبان گیری کنید.

## گام ۲ — جایگزینی فایل‌ها

1. فایل zip نسخه‌ی جدید را Extract کنید.
2. پوشه‌ی `storage` و فایل `.env` را نگه دارید.
3. فایل‌های قدیمی با فایل‌های جدید جایگزین می‌شوند.

## گام ۳ — Build

اگر `package.json` تغییر کرده است، `dist/` را دوباره Build کنید:

```
rm -rf dist && npm run build
```

## گام ۴ — اجرای Migration

```
npm run migrate
```

## گام ۵ — Restart اپ

1. در cPanel، صفحه‌ی **Setup Node.js App** را باز کنید.
2. گزینه‌ی **Restart** را انتخاب کنید.

> نکته‌ی: فایل `.env` تغییر نمی‌کند.

برای رفع خطا، `09-troubleshooting.md` را باز کنید.
